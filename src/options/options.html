Settings. Nothing here is required. It works as soon as it's installed.

Where downloads go

Checking…

This is automatic. If you have a download manager with a Chrome extension (Internet Download Manager, Free Download Manager, Motrix, JDownloader, Gopeed, Neat Download Manager, AB Download Manager…), it takes over each file. If you don't, or its browser integration is switched off, Chrome downloads the files itself, with full progress in the panel.

Tips for download managers: turn off the dialog that asks you to confirm each download, so dozens of files can be added at once. Download managers choose their own save folders, so the Drive folder structure only applies to Chrome downloads.

Files

File names and extensions are kept exactly as Google has them, for example C4642.MP4. The only exception is characters your computer can't store in a name (\ / : * ? " < > |), which become _.

Google Docs, Sheets and Slides

These have no file of their own, so they're saved in the format you choose.

Advanced: Google connection

If a Client ID is saved, it's also used automatically as a backup whenever the normal mode can't read a folder.

Privacy

Everything runs on your computer. There's no server. Files go straight from Google to Chrome or your download manager. If a download manager takes over a file, its own browser extension hands it your Google login for that download, the same as when you click any download link.
